VULKANOS PC - ROM FOLDERS

Copy your legally obtained game files into the matching platform folder.
Examples:
  nes       NES
  snes      Super Nintendo
  gb        Game Boy
  gbc       Game Boy Color
  gba       Game Boy Advance
  megadrive Sega Mega Drive / Genesis

ES-DE reads the ~/ROMs folder and builds the game list automatically.
No game ROMs or BIOS files are included in VulkanOS.
