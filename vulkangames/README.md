# VulkanGames.io

Standalone portal landing page stored under `/vulkangames/` in the VulkanOS project site.

## Current scope

- Responsive VulkanGames brand and arcade portal layout.
- Searchable catalogue shell and category filters.
- Explicit placeholder catalogue until games are original, open source, or redistributed with permission.
- No proxy, mirror, iframe wrapper for blocked sites, tunnelling, or filter circumvention.

## Publishing

The parent repository's GitHub Pages workflow publishes the repository root. After deployment, this page will be available at:

https://enzolas140-ai.github.io/vulkanos-flap/vulkangames/

The `vulkangames.io` name is branding only until the domain is registered and DNS is configured. A custom domain requires registration by the owner and GitHub Pages DNS configuration.

## Adding a game

Only add games when the creator's licence permits hosting/embedding or explicit permission has been granted. Retain required attribution, source/license notices and any third-party assets notices. Do not upload ROMs, proprietary game builds, or copyrighted assets without rights.
